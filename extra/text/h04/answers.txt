Навіщо в програмуванні окремий тип для «так» і «ні»?
Для зручності та безпеки. Запобігає спроб множення і тд, при цьому логічні оператори можуть працювати і з іншими типами даних

Як сказати !(a && b) людською мовою?
Неправда, що обидві умови виконуються одночасно

Чим && відрізняється від &?
&& не буде аналізувати другу частину, якщо перша видає false, використовується лише для логічних виразів, безпечніший
& використовується як для чисел так і для логічних виразів, виконає другу частину, навіть якщо перша видала false

Чому програма не падає в if (x != null && x.name == "Іван"), хоча x порожній?
через вище наведену особливість з &&

Як запхати 32 відповіді «так/ні» в одне число?
Змінна для числа складається з бітів, записати 0\1 в біти, у результаті ми отримаємо довільне число, але в бітовому виражкнні це буде потрібна нам послідовність так та ні

Що швидше: n % 2 чи n & 1?
В теорії оерація n&1 швидше, на практиці можуть працювати однаково швидко
